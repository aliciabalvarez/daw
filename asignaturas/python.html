    Tema 1

    Identificación de los elementos de un programa informático.

    Un programa se construye con elementos básicos: instrucciones simples y compuestas, identificadores, constantes, tipos primitivos (enteros, flotantes, cadenas, booleanos), estructuras de datos (listas, tuplas, diccionarios), estructuras de control (condicionales y bucles), funciones y librerías. Usar bien variables, tipos, operadores, conversiones, literales, constantes y comentarios permite escribir código claro, eficiente y mantenible.

    1. Estructura y bloques fundamentales.

    Las estructuras y bloques fundamentales son la forma en que se organiza y agrupa el código. A diferencia de otros lenguajes que usan llaves {}, Python usa la indentación (sangrado) para delimitar los bloques. No es una cuestión de estilo: es un requisito sintáctico que define el alcance de instrucciones, condicionales, bucles y funciones.

    Organizar el código en bloques lo hace modular, legible y mantenible, y permite dividir el programa en partes reutilizables. Dominarlo es la base para conceptos posteriores como la programación orientada a objetos o el manejo de excepciones.

    1.1. Estructura y organización en Python: clave en las primeras fases del aprendizaje.

    Un buen programa sigue un flujo lógico ordenado: variables, operadores y comentarios bien usados; funciones que dividen el problema en partes reutilizables; y condicionales y bucles colocados con orden. Un código claro y coherente facilita detectar errores (depuración) y prepara para trabajar más adelante con clases, archivos y bases de datos.

    Aspectos clave de una buena organización:

    • Claridad: dividir el programa en secciones (comentarios, funciones, bloques).
    • Buenas prácticas: indentación correcta, nombres significativos, constantes y la guía de estilo PEP 8.
    • Depuración: una estructura clara ayuda a localizar fallos con print() o el depurador.
    • Escalabilidad y transferencia: una base ordenada facilita crecer hacia proyectos grandes y aprender otros lenguajes.

    Ejemplo: programa bien organizado

    # Programa: Evaluación de promedio
# Función para calcular promedio
def calcular_promedio(nota1, nota2):
    return (nota1 + nota2) / 2

# Programa principal
nota1 = float(input("Ingrese la primera nota: "))
nota2 = float(input("Ingrese la segunda nota: "))
promedio = calcular_promedio(nota1, nota2)

# Estructura condicional
if promedio >= 5.0:
    print("El estudiante aprueba con promedio:", promedio)
else:
    print("El estudiante reprueba con promedio:", promedio)

    Es claro porque usa comentarios que documentan cada parte, nombres de variables significativos, una función que separa el cálculo de la lógica principal (modularidad) y un condicional bien diferenciado.

    1.2. Elementos estructurales esenciales en un programa Python.

    Los elementos básicos son las instrucciones, los bloques definidos por indentación, las estructuras de control, las funciones y los comentarios.

    🔹 Declaraciones (sentencias simples)

    Instrucciones individuales que se ejecutan en orden: asignar valores, mostrar mensajes, operar. Es el nivel más básico de ejecución.

    nombre = "Carlos"
print("Hola,", nombre)

    🔹 Funciones

    Agrupan un bloque de código bajo un nombre para reutilizarlo y dividir el problema en partes más simples.

    def saludar(nombre):
    print("Hola,", nombre)

    🔹 Condicionales

    if, elif, else permiten tomar decisiones según una expresión lógica y controlar el flujo del programa.

    if edad >= 18:
    print("Eres mayor de edad")
else:
    print("Eres menor de edad")

    🔹 Bucles (iteraciones)

    for y while repiten un bloque mientras se cumpla una condición o recorriendo un iterable (lista, rango…).

    for i in range(5):
    print("Número:", i)

    🔹 Módulos e importaciones

    Los módulos dividen el programa en archivos separados. Con import se incorporan librerías estándar o módulos propios.

    import math
print(math.sqrt(16))

    1.3. Errores comunes al trabajar con los bloques estructurales en Python.

    Los fallos más habituales al empezar: falta de indentación, instrucciones mal alineadas, estructuras mal anidadas, usar funciones sin definirlas u olvidar importar módulos.

    🔹 Olvidar la indentación al utilizar estructuras como if, for o def

    Sin sangría Python no sabe dónde empieza el bloque y da error de sintaxis.

    🔹 Usar variables no inicializadas

    Usar una variable sin haberle asignado un valor antes produce NameError.

    ✅ Corrección
    nombre = "Ana"

    🔹 Definir funciones sin ejecutarlas

    Definir una función no la ejecuta: hay que llamarla explícitamente.

    ✅ Corrección

    2. Variables.

    Una variable es un nombre asociado a un valor guardado en memoria. Funciona como un contenedor cuyo contenido puede cambiar durante la ejecución. En Python no hace falta indicar el tipo al crearla.

    Son la base para entender después tipos de datos, operadores, estructuras de control, funciones, listas, diccionarios u objetos.

    2.1. Características principales de las variables en Python.

    📦 Asignación múltipleVarias variables en una línea.a, b, c = 1, 2, 3
    🗂️ Referencia a objetosLa variable guarda una referencia, no el valor. Dos nombres pueden apuntar a la misma lista.lista2 = lista1 → modificar una modifica la otra

Python asigna el tipo automáticamente según el valor, pero hay que saber reconocerlos y elegir el adecuado (int, float, str, bool) para evitar errores como operar con tipos incompatibles.

    4. Literales.

    Los literales son valores fijos escritos directamente en el código, sin guardarlos en una variable: 42, "Hola mundo", True, [1, 2, 3]. Se usan en asignaciones, impresiones, condiciones o retornos.

    🌱 Reconocer los distintos tipos de datos desde su forma escrita

    La forma en que se escribe un literal indica su tipo:

    print(25)      # int
print(3.14)    # float
print("Hola")  # str
print(True)    # bool

    🧠 Asimilar la sintaxis de Python de forma natural

    Se pueden ejecutar instrucciones con literales sin declarar variables: print(10 + 5).

    🛠️ Construir ejemplos funcionales desde el primer día

    Permiten probar cosas rápidamente en consola, IDLE o Jupyter: print(4 * 3), print("Python" * 2).

    🔎 Detectar errores comunes asociados al mal uso de los datos

    ❌ Error
    print("5" + 2)      # TypeError
print("True" == True) # False
    ✅ Corrección
    print(int("5") + 2) # 7
print(True == True) # True

    5. Constantes.

    Una constante es un valor que no debe cambiar durante la ejecución (tasas, límites, configuraciones). Python, a diferencia de Java, C++ o C#, no tiene palabra clave const o final: técnicamente son variables y se pueden modificar. Se distinguen por convención:

    • Se escriben en MAYÚSCULAS con guiones bajos: PI = 3.1416, VELOCIDAD_LUZ = 299792458, MAX_INTENTOS.
    • Se declaran al inicio del archivo o módulo, separadas del resto, a menudo con un comentario # Constantes globales.
    • Modificarlas se considera un error; depende de la disciplina del programador.

    Ventajas: código más claro, se evitan cambios accidentales y los valores se actualizan en un solo sitio.

    6. Operadores y expresiones.

    Un operador es un símbolo que indica una operación sobre uno o más operandos (literales, variables u otras expresiones): + - * / == and or in ** not +=.

    Una expresión es una combinación válida de valores, variables, operadores y funciones que Python evalúa para obtener un resultado. Puede asignarse a una variable, evaluarse en una condición (if, while) o formar parte de un cálculo mayor.

    resultado = (a + b) * 2   # + y * son operadores; a, b y 2 son operandos

    6.1. Tipos de operadores en Python.

    TipoQué haceError típicoEjemplo
    ➕ AritméticosOperaciones matemáticas (+ - * / // % **).Confundir / con // (división entera).10 // 3 → 3
    🔄 AsignaciónAsignan y actualizan (= += -=…).No entender los compuestos.x += 2 ≡ x = x + 2
    ⚖️ ComparaciónComparan y devuelven booleano (== != < > <= >=).Confundir = con ==.10 == 5 → False

    🆔 IdentidadComprueban si dos variables son el mismo objeto (is, is not).Usar == cuando toca is.y = x; x is y → True
    🛠️ Bit a bitOperan sobre la representación binaria.Confundir & con and.6 & 3 → 2

    6.2. La importancia de enseñar operadores y expresiones en Python.

    Los operadores y expresiones son el puente entre datos y resultados, y conectan variables con condicionales y bucles. Permiten:

    • Construir lógica combinando valores: resultado = (5 + 3) * 2.
    • Escribir condiciones compuestas: if x > 0 and y > 0:.
    • Representar cálculos directamente: area = base * altura / 2, precio_final = precio - (precio * descuento / 100).
    • Detectar errores por el orden de evaluación: (3 + 2) * 4 no es igual a 3 + (2 * 4).
    • Preparar expresiones más complejas en bases de datos, archivos y POO: valido = (edad >= 18) and (pais == "España").

    7. Conversiones de tipo.

    Sirven para evitar errores al operar con tipos incompatibles, garantizar la integridad de los datos que llegan del teclado, archivos o interfaces externas, y adaptar los datos al contexto (algoritmos, condiciones, salida formateada).

    8. Comentarios.

    Los comentarios son textos dentro del código que el intérprete ignora. Sirven para explicar, documentar o anotar partes del programa. Se escriben con # al inicio de la línea o detrás de una instrucción:

    print("Hola")  # Este comentario explica esta línea

    Para documentar funciones, clases y módulos se usan docstrings (cadenas entre comillas triples """).

    Se usan para documentar el funcionamiento, explicar decisiones técnicas, marcar partes pendientes y facilitar el trabajo en equipo o revisar el código tiempo después.

    El lenguaje Python

    Python es un lenguaje de alto nivel, interpretado y multiparadigma (estructurado, orientado a objetos o funcional, incluso combinados). Es fácil de aprender, rápido para escribir código nuevo, gratuito, abierto y multiplataforma.

    A diferencia de los lenguajes compilados (C, Java), Python no genera código máquina directamente:

    • El código fuente (.py) se compila a bytecode (.pyc).
    • El bytecode lo interpreta la PVM (Python Virtual Machine), que lo convierte en código binario y lo ejecuta.

    Esto le da portabilidad: el mismo programa funciona en cualquier sistema operativo sin tocar el código.

    Qué se necesita para ejecutar Python

    • El intérprete de Python — lee, traduce y ejecuta el código. Incluye el compilador a bytecode y la PVM. Descarga: python.org.
    • Un editor o IDE — donde escribir el código. Opciones: editores simples (Bloc de notas, Notepad++, Sublime Text) o entornos completos (Visual Studio Code, PyCharm, Thonny, IDLE).

    Las variables y referencias en Python

    En Python una variable no guarda el valor directamente: actúa como una etiqueta que apunta a una posición de memoria donde vive el objeto.

    x = 5     # x apunta al objeto 5
y = x     # y apunta al mismo objeto
x = 10    # x pasa a apuntar a 10; y sigue en 5
print(id(x), id(y))  # id() muestra la dirección de memoria

    Reglas para nombrar variables: deben empezar por letra o _, solo letras/números/guiones bajos, son case-sensitive (Edad ≠ edad), sin espacios ni símbolos. Convención: snake_case y nombres descriptivos (precio_total en vez de x).

    1. Comprobador de Palíndromos

    Determina si una palabra se lee igual al derecho que al revés (ej: "radar", "oso").

    • Pide una palabra al usuario.
    • Conviértela a minúsculas (.lower()) para evitar problemas con mayúsculas.
    • Compara la palabra con su versión invertida y muestra True o False.
    🔑 Pista: "hola"[::-1] → "aloh". El [::-1] es slicing con paso −1: recorre la cadena al revés.

    2. Contraseña con vocales y números

    Comprueba si una contraseña cumple tres condiciones y muestra el resultado de cada una:

    • Tiene al menos 8 caracteres → len(password) >= 8
    • Contiene al menos una vocal (mayúscula o minúscula) → in
    • Contiene al menos un dígito (0–9) → in

    Al final indica si la contraseña es segura (las tres condiciones) o débil.

    3. Casting y operadores con texto y números

    Practica la diferencia entre operar con números y con cadenas:

    • Pide un número escrito como texto (ej: "25") y otro número entero real (ej: 5).
    • Convierte el texto a número con int().
    • Muestra en un solo print(): la suma numérica y la repetición del texto ("25" * 5 → "2525252525").
    🔑 "25" es texto → no se puede sumar directamente. int("25") + 5 → 30. "25" * 5 → "2525252525".

    4. Lógica booleana en una sola expresión

    Comprueba si un número cumple dos condiciones a la vez:

    • Está entre 1 y 100 (ambos incluidos): 1 <= x <= 100
    • Es múltiplo de 3 o de 5: x % 3 == 0 or x % 5 == 0

    Muestra el resultado de tres formas: con variables normales, con f-string simple y con f-string con operación.

    5. Casting con valores booleanos

    Pide al usuario tres valores (texto, entero, decimal), conviértelos a bool() y muestra si cada uno es True o False.

    🔑 En Python: bool(0) → False, bool("") → False. Todo lo demás es True.

    6. Comprobación de campos vacíos con booleanos

    Pide nombre, correo y edad al usuario. Convierte cada dato a bool() y muestra si se rellenó o quedó vacío. Al final indica si todos los campos están completos.

    🔑 input() devuelve "" si el usuario pulsa Enter sin escribir nada → bool("") == False. Combina con and para comprobar todos.

    7. Comprobación de números positivos con booleanos

    Pide tres números enteros. Convierte cada uno a bool() y determina si al menos dos son positivos (distintos de 0).

    (bool(a) and bool(b)) or (bool(a) and bool(c)) or (bool(b) and bool(c))
    🔑 bool(0) → False. Cualquier número positivo o negativo distinto de 0 → True.

    8. Comparación de edades

    Pide las edades de dos personas y muestra con True/False:

    • Si la primera es mayor que la segunda.
    • Si la primera es menor que la segunda.
    • Si ambas tienen la misma edad.

    9. Cálculo del IMC (sin if)

    Calcula el Índice de Masa Corporal a partir del peso (kg) y la altura (m).

    imc = peso / altura ** 2
    • Muestra el IMC con dos decimales.
    • Imprime tres expresiones booleanas indicando si es: bajo peso (imc < 18.5), peso normal (18.5 <= imc <= 24.9) o sobrepeso (imc >= 25).
    🔑 Usa ** para la potencia y comparaciones encadenadas como 18.5 <= imc <= 24.9.

    10. Mostrar una tabla con caracteres de escape

    Muestra una tabla con nombres y edades de dos personas, alineada en columnas con caracteres de escape:

    • \t → tabulación (separación entre columnas)

    11. Combinación alterna de letras (cadenas de 5 caracteres)

    Trabaja con dos textos de exactamente 5 caracteres. El programa debe:

    • Imprimir las dos cadenas separadas por |.
    • Crear una nueva cadena tomando letras alternas: letra 0 de la 1ª, letra 1 de la 2ª, letra 2 de la 1ª, letra 3 de la 2ª… usando indexación y concatenación.
    • Mostrar la nueva cadena en mayúsculas.
    • Imprimir las tres cadenas separadas por puntos (sep=".").
    🔑 Usa texto1[0] + texto2[1] + texto1[2] + texto2[3]… Sin if ni bucles.

    12. Combinación e inversión de cadenas

    Pide dos cadenas al usuario. El programa debe:

    • Imprimirlas separadas por _.
    • Tomar las 3 primeras letras de la primera (texto[:3]) y las 3 últimas de la segunda (texto[-3:]).
    • Unirlas en una nueva cadena y mostrarla invertida ([::-1]).
    • Mostrar las tres cadenas separadas por comas.

    13. Manipulación de dos cadenas

    Pide dos cadenas al usuario y realiza estas operaciones:

    • Muestra cuántas letras tiene cada una (len()).
    • Crea una nueva cadena con: desde la 3ª letra de la primera hasta el final (texto1[2:]) + la primera mitad de la segunda (texto2[:len(texto2)//2]).
    • Muestra la nueva en mayúsculas.
    • Imprime las tres cadenas separadas por - en una sola línea.

    # Errores corregidos:
# 1. x e y no se convertían a float → añadido float()
# 2. z tenía indentación incorrecta → eliminados los espacios
# 3. Faltaba la coma en print("Consumo cada 100 km:" z) → añadida

print("Coste del viaje:", coste, "€")
